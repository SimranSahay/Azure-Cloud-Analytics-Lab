# Experiment 01 – Azure Data Factory Data Ingestion

## Aim

To create an Azure Data Factory pipeline to ingest data from an on-premises SQL database into Azure Blob Storage.

## Azure Services Used

- Azure Data Factory
- On-premises SQL Server
- Azure Blob Storage
- Self-hosted Integration Runtime

## Implementation

The pipeline was created in Azure Data Factory to extract data from the on-premises SQL database and load it into Azure Blob Storage.

## Output

Screenshots showing the configuration, pipeline execution, and successful data ingestion are provided in this folder.

## Result

The Azure Data Factory pipeline was successfully created and the data was ingested from the on-premises SQL database into Azure Blob Storage.
