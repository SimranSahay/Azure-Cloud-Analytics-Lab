# Experiment 06: Integrate Azure Data Factory with Databricks for End-to-End Data Pipeline Orchestration

## Course Outcome

CO3

## Aim

To integrate Azure Data Factory with Azure Databricks for end-to-end data pipeline orchestration.

## Software and Services Required

* Microsoft Azure Account
* Azure Data Factory
* Azure Databricks Workspace
* Apache Spark
* Python
* PySpark
* Azure Storage

## Theory

Azure Data Factory is a cloud-based data integration service used to create, schedule, and manage data pipelines.

Azure Databricks is a cloud-based analytics platform that provides Apache Spark capabilities for processing and transforming large datasets.

Integration of Azure Data Factory with Azure Databricks enables automated data workflows. Azure Data Factory can orchestrate pipeline activities and trigger Databricks notebooks to perform data processing tasks.

This integration supports end-to-end data pipeline management, from data ingestion to transformation and processing.

## Procedure

1. Access the Microsoft Azure Portal.
2. Create or access an Azure Data Factory instance.
3. Open the Azure Data Factory Studio.
4. Access or create an Azure Databricks workspace.
5. Configure the required connection between Azure Data Factory and Azure Databricks using a linked service.
6. Create or select a Databricks notebook for data processing.
7. Create a pipeline in Azure Data Factory.
8. Add a Databricks Notebook activity to the pipeline.
9. Configure the notebook activity and its required settings.
10. Validate and execute the pipeline.
11. Monitor the pipeline execution and observe the results.

## Result

Azure Data Factory was integrated with Azure Databricks to demonstrate end-to-end data pipeline orchestration. The experiment illustrates automated workflow management and data processing using Azure cloud services.
