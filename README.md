# Azure Cloud Analytics Lab

This repository contains the experiments performed as part of the Cloud Analytics Lab using Microsoft Azure services.

## Experiments

| **Experiment** | **Title**                                                                                                      | **Status** |
| -------------- | -------------------------------------------------------------------------------------------------------------- | ---------- |
| Experiment 01  | Create an Azure Data Factory pipeline to ingest data from an on-premises SQL database into Azure Blob Storage. | Completed  |
| Experiment 02  | Create an Azure Synapse dedicated SQL pool and load data.                                                      | Completed  |
| Experiment 03  | Query and analyze structured and unstructured data from Azure Data Lake Storage using Synapse.                 | Completed  |
| Experiment 04  | Use Azure Databricks for data preprocessing and machine learning.                                              | Completed  |
| Experiment 05  | Process real-time streaming data using Databricks & Azure Event Hub.                                           | Completed  |
| Experiment 06  | Integrate Azure Data Factory with Databricks for end-to-end data pipeline orchestration.                       | Completed  |

## Azure Services Used

* Azure Data Factory
* Azure Blob Storage
* Azure Synapse Analytics
* Azure Data Lake Storage
* Azure Databricks
* Azure Event Hubs
