# Experiment 05: Process Real-Time Streaming Data Using Databricks & Azure Event Hub

## Course Outcome

CO3

## Aim

To process real-time streaming data using Azure Databricks and Azure Event Hub.

## Software and Services Required

* Microsoft Azure Account
* Azure Databricks Workspace
* Azure Event Hubs
* Apache Spark
* Python
* PySpark

## Theory

Azure Event Hubs is a cloud-based event streaming platform that enables the collection and processing of large volumes of real-time data.

Azure Databricks provides a distributed data processing environment using Apache Spark. It supports Structured Streaming, which allows continuous processing of incoming data streams.

By integrating Azure Event Hubs with Azure Databricks, real-time data can be ingested, processed, and analyzed efficiently.

## Procedure

1. Access the Microsoft Azure Portal.
2. Create or access an Azure Event Hubs namespace.
3. Create an Event Hub within the namespace.
4. Configure the required event streaming settings.
5. Access the Azure Databricks workspace.
6. Create a notebook for streaming data processing.
7. Configure the connection between Azure Databricks and Azure Event Hubs.
8. Read incoming streaming data using Spark Structured Streaming.
9. Process and transform the incoming data.
10. Execute the streaming workflow and observe the results.

## Result

Real-time streaming data processing was demonstrated using Azure Databricks and Azure Event Hubs. The experiment illustrates how streaming data can be ingested and processed using cloud-based services.
