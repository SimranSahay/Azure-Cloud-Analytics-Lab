# Experiment 03 – Query and Analyze Data Using Synapse

## Aim

To query and analyze structured and unstructured data from Azure Data Lake Storage using Azure Synapse Analytics.

## Azure Services Used

- Azure Data Lake Storage
- Azure Synapse Analytics

## Implementation

Data stored in Azure Data Lake Storage was accessed and queried using Azure Synapse Analytics. SQL queries were executed to retrieve and analyze the data, and the query results were visualized for analysis.

## Output

Screenshots showing the SQL queries, query execution, errors encountered during the process, successful query results, and data visualization are provided in this folder.

## Result

The data stored in Azure Data Lake Storage was successfully queried and analyzed using Azure Synapse Analytics.
